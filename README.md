# Neutrino Oscillation Simulator

A Python toolkit for the numerical simulation of neutrino oscillations in vacuum and matter.

This project aims to provide a modular, transparent and well-documented implementation of neutrino oscillation physics, with a focus on numerical methods and reproducible scientific computing.

---

## Features (planned)

- [ ] PMNS matrix implementation
- [ ] Two-flavour oscillations
- [ ] Three-flavour oscillations
- [ ] Vacuum propagation
- [ ] Matter effects (MSW)
- [ ] Numerical integration of the evolution equation
- [ ] Oscillation probability plots
- [ ] Comparison with NuFIT parameters
- [ ] Unit tests
- [ ] Documentation

## Goals

The objective of this project is to develop a reusable scientific toolkit for neutrino oscillation studies, following software engineering practices commonly used in computational physics research.

The project is intended both as a learning exercise and as a foundation for future research-oriented developments in particle physics.
